
## 📌 Project Overview


This project focuses on analyzing Walmart store sales data using **MySQL**.


The objective of this project is to use SQL queries to analyze sales performance, customer purchasing behavior, product-line profitability, payment methods, monthly sales trends, and other important business metrics.


The project contains **10 SQL analysis tasks**, with each task addressing a specific business question and generating actionable insights from the Walmart sales dataset.

🔍 SQL Analysis Tasks
Task 1 — Monthly Sales by Branch
Business Question

Analyze the monthly sales performance of each Walmart branch.

SQL Approach

The query extracts the month from the transaction date and calculates total monthly sales for each branch.

SELECT Branch, 
       MONTH(Date) AS Month_No,
       ROUND(SUM(Total),2) AS Monthly_Sales
FROM walmart_sales
GROUP BY Branch, Month_No
ORDER BY Branch, Month_No;
Analysis

This analysis helps identify:

Monthly sales trends
High-performing branches
Seasonal sales patterns
Changes in branch performance

💰 Task 2 — Profit by Branch and Product Line
Business Question

Determine the total profit generated by each product line within every branch.

SELECT Branch, `Product line`,
       ROUND(SUM(`gross income`),2) AS Total_Profit
FROM walmart_sales
GROUP BY Branch, `Product line`
ORDER BY Branch, Total_Profit DESC;
Analysis

This helps identify:

Most profitable product lines
Least profitable product lines
Branch-wise profitability
Products requiring additional attention

Output: Task_2.png

👤 Task 3 — Customer Spending Categorization
Business Question

Categorize customers according to their total spending.

Customers are classified into:

High Spender
Medium Spender
Low Spender
SELECT `Customer ID`,
       ROUND(SUM(Total),2) AS Total_Spending,
       CASE 
         WHEN SUM(Total) >= 1000 THEN 'High Spender'
         WHEN SUM(Total) BETWEEN 500 AND 999 THEN 'Medium Spender'
         ELSE 'Low Spender'
       END AS Spending_Category
FROM walmart_sales
GROUP BY `Customer ID`
ORDER BY Total_Spending DESC;
Analysis

This analysis helps the business understand customer value and identify high-value customers.

Output: Task_3.png

📈 Task 4 — Sales Outlier Detection
Business Question

Identify transactions that are significantly higher or lower than the normal sales level within their respective product line.

The analysis uses:

Average sales
Standard deviation
Two-standard-deviation threshold
SELECT `Invoice ID`, `Product line`, Total
FROM walmart_sales ws
WHERE Total > (
    SELECT AVG(Total) + 2*STDDEV(Total) 
    FROM walmart_sales 
    WHERE `Product line` = ws.`Product line`
)
OR Total < (
    SELECT AVG(Total) - 2*STDDEV(Total) 
    FROM walmart_sales 
    WHERE `Product line` = ws.`Product line`
);
Analysis

Outlier detection can help identify:

Unusual transactions
Exceptional purchases
Potential data-quality issues
Sales anomalies

Output: Task_4.png

💳 Task 5 — Payment Method Analysis
Business Question

Analyze the number of transactions made using each payment method across different cities.

SELECT City, Payment, COUNT(*) AS Payment_Count
FROM walmart_sales
GROUP BY City, Payment
ORDER BY City, Payment_Count DESC;
Analysis

This helps understand:

Customer payment preferences
City-wise payment behavior
Popular payment methods
Payment trends

👨‍🦰👩 Task 6 — Monthly Sales by Gender
Business Question

Compare monthly sales performance between male and female customers.

SELECT MONTH(STR_TO_DATE(Date, '%d-%m-%Y')) AS Month_No,
       Gender,
       ROUND(SUM(Total),2) AS Total_Sales
FROM walmart_sales
GROUP BY Month_No, Gender
ORDER BY Month_No, Gender;
Analysis

This analysis helps identify:

Monthly gender-wise sales trends
Differences in purchasing behavior
Months with higher customer activity

Output: Task_6.png

🛍️ Task 7 — Customer Type and Product Line Analysis
Business Question

Analyze sales based on customer type and product line.

SELECT `Customer type`, `Product line`,
       ROUND(SUM(Total),2) AS Total_Sales
FROM walmart_sales
GROUP BY `Customer type`, `Product line`
ORDER BY `Customer type`, Total_Sales DESC;
Analysis

This helps determine:

Sales generated by different customer types
Popular product lines
Product preferences of customer segments

🔁 Task 8 — Repeat Customers
Business Question

Identify customers who have made more than one purchase.

SELECT `Customer ID`, COUNT(*) AS Purchase_Count
FROM walmart_sales
GROUP BY `Customer ID`
HAVING Purchase_Count > 1
ORDER BY Purchase_Count DESC;
Analysis

This analysis helps identify:

Repeat customers
Customer loyalty
Purchase frequency
Potential customers for loyalty programs

Output: Task_8.png

🏆 Task 9 — Top 5 Highest-Spending Customers
Business Question

Identify the five customers with the highest total spending.

SELECT `Customer ID`, ROUND(SUM(Total),2) AS Total_Spending
FROM walmart_sales
GROUP BY `Customer ID`
ORDER BY Total_Spending DESC
LIMIT 5;
Analysis

This helps identify high-value customers who may be important for:

Customer retention
Loyalty programs
Personalized offers
Premium customer strategies

Output: Task_9.png

📅 Task 10 — Sales by Day of Week
Business Question

Analyze total sales according to the day of the week.

SELECT DAYNAME(STR_TO_DATE(Date, '%d-%m-%Y')) AS Day_Name,
       ROUND(SUM(Total),2) AS Total_Sales
FROM walmart_sales
GROUP BY Day_Name
ORDER BY Total_Sales DESC;
Analysis

This helps determine:

Highest-selling days
Lowest-selling days
Weekly sales patterns
Potential opportunities for promotions
